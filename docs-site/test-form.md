# Test form

Use this page as a plain test form. It is intentionally not wired to watasu,
Agent Cards, external agents, or any hosted submit route.

The form below saves submitted entries only in this browser session. It does not
send the values to a server, add them to the URL, write them to localStorage, or
print them to the console. Reloading the page in the same tab should keep the
entries available until the browser session ends or you clear them.
